# Arquitectura de CloudBox

Este documento describe la arquitectura general del proyecto.

CloudBox está dividido principalmente en:

- Frontend
- Backend
- Base de datos

Frontend:
Contiene la interfaz gráfica y la interacción con el usuario.

Backend:
Contiene la lógica de negocio, autenticación, validaciones
y comunicación con la base de datos.

Base de datos:
Almacena la información estructurada del sistema.

La comunicación entre Frontend y Backend se realiza mediante
una API.
