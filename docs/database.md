# Base de Datos CloudBox

Este documento describe las tablas utilizadas por CloudBox
y las relaciones existentes entre ellas.

Antes de modificar una tabla, verificar primero el diagrama
de base de datos para evitar romper las relaciones existentes.

Las entidades principales incluyen:

- Usuario
- Archivo
- Carpeta
- Compartir
- Método de pago
- Comprobante de pago

Cualquier modificación estructural de la base de datos debe
ser comunicada al equipo antes de implementarse.
