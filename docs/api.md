# API de CloudBox

Este documento contiene los endpoints disponibles en el backend.

Cada endpoint debe documentar:

- Método HTTP.
- URL.
- Parámetros.
- Body.
- Autenticación requerida.
- Respuesta exitosa.
- Posibles errores.

Ejemplo:

POST /api/auth/login

Descripción:
Permite iniciar sesión en CloudBox.

La documentación debe mantenerse actualizada cuando se agreguen
o modifiquen endpoints.
